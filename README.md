# ParkEye 파크아이 — 다운로드

AI 번호판 인식 주차 관리 프로그램. Windows 10/11 64비트.

## 내려받기

**[최신 버전 내려받기](../../releases/latest)**

설치 파일 하나로 끝납니다. Python이나 별도 구성 요소를 설치할 필요가 없고,
인식 모델이 함께 들어 있어 **인터넷 없이도 동작**합니다.

## 설치

1. 내려받은 `ParkEye_Setup_x.y.z.exe` 실행 (관리자 권한 필요)
2. 설치 위치는 기본값 그대로 두셔도 됩니다
3. **무인 운영**을 하실 경우 설치 중 아래 항목을 체크하세요

   ```
   [✓] 컴퓨터를 켤 때 실시간 감시 자동 시작
   ```

   정전이나 재부팅 뒤에도 감시가 자동으로 다시 시작됩니다. 이 항목을 빠뜨리면
   재부팅된 시간대의 입출차 기록이 통째로 비게 됩니다.

> 백신이 설치 파일을 차단할 수 있습니다. 서명되지 않은 신규 프로그램에 대한
> 일반적인 반응이며, 차단되면 예외로 등록한 뒤 다시 실행하세요.

## 처음 사용하기

프로그램을 열고 **`사용 안내`** 버튼을 누르면 8단계 가이드가 나옵니다.
카메라를 연결하기 전에 **사진 몇 장으로 인식이 잘 되는지 먼저 확인**하시길 권합니다.

- `사진 열기` 또는 `폴더 열기`로 주차장 사진을 불러옵니다
- 파일명에 번호판이 들어 있으면 자동으로 채점됩니다
- `보기 → 문제만` 필터로 틀린 것만 모아 볼 수 있습니다

## 체험과 라이선스

- 설치 후 **30일간 모든 기능**을 쓸 수 있습니다
- 이후 실시간 감시를 계속하려면 라이선스가 필요합니다
  (사진 판독 기능은 계속 사용 가능)
- 라이선스 문의 시 프로그램의 `정보` 화면에 있는 **기기 ID**를 알려 주세요
- 활성화한 뒤에는 **만료일까지 인터넷 없이도 동작**합니다
